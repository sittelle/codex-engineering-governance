### Behavioral governance — PASS

- no Critical test scored 0;
- required-assurance nonexecution regression closed;
- destructive-data intentional-obsolescence regression closed.

### Real-project proportionality — PASS
- high-consequence C3 project;
- small M1/SA1 local utility;
- ordinary M1/SA1 local-first application with persistence, CSV import/export, and dependencies.

Observed desired behavior included recommendation-first decisions, progressive questioning, release blocking where required, authentication/authorization separation, dependency restraint, truthful VERIFIED/UNVERIFIED distinctions, Git evidence boundaries, canonical verification bootstrap, and proportionate documentation.

### Project lifecycle tooling — PASS
Validated New dry-run, New apply, existing-target refusal, legacy adoption, preservation of existing AGENTS.md, and refusal to Adopt an already-governed project. New / Adopt / Update remain distinct lifecycle operations.

## Freeze rule

Do not broaden the global baseline without evidence. Allowed reasons: reproducible regression, security defect, integration/compatibility defect, repeated cross-project proportionality failure, or intentionally planned workflow/profile expansion with tests.
