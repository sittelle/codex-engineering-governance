# Security Model

Assurance: <SA0|SA1|SA2|SA3>

Document as applicable:
- security objectives/assets;
- actors/threat actors;
- entry points;
- trust/privilege boundaries;
- sensitive data;
- authentication;
- authorization;
- secrets;
- cryptography;
- untrusted input/file handling;
- logging;
- supply chain/CI;
- security assumptions;
- threats/controls/residual risks;
- required security verification;
- findings/accepted risks/exceptions.

Readiness: SECURITY READY / READY WITH ACCEPTED RISKS / NOT READY / INCOMPLETE ASSURANCE.
