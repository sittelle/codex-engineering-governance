# SQLite Profile

Use SQLite as a serious embedded relational DB when single-device/local/moderate-concurrency characteristics fit.

Use deliberate app-data location/permissions, parameterized SQL, transactions, constraints, versioned migrations, and realistic integration tests. Understand foreign-key configuration, lock/busy behavior, WAL implications, backups, and concurrency.

Do not use unsafe network-share patterns, concatenate untrusted SQL, or perform destructive migrations without analysis.
